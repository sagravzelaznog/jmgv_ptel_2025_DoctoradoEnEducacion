# Acciones

Asunto: Creación de una Aplicación Web Modular y Responsiva (Enfoque de Archivo Único)

Objetivo: Desarrolla una aplicación web completa en archivo HTML (index.html) preparar para agregar modulos html de cursos . El diseño debe ser profesional, limpio, y completamente responsivo (adaptable a móviles, tablets y escritorio).

La estructura interna del archivo debe estar optimizada para máxima mantenibilidad y escalabilidad.

Requerimientos de Implementación:

Archivo Único: Todo el código (HTML, CSS, y JS) debe estar contenido en un solo archivo.

Módulo de Estilos (Tailwind CSS):

No uses CSS tradicional en una etiqueta <style>.

Usa temas de colores profesional  entre azul y Esmeralda 

Implementa Tailwind CSS para todos los aspectos visuales y de layout.

Carga Tailwind usando su CDN oficial en la etiqueta <head>.

Utiliza las utilidades responsivas de Tailwind (ej. sm:, md:, lg:) extensivamente para asegurar que la aplicación se vea excelente en todos los dispositivos.

Módulo de Contenido (HTML Semántico):

Estructura el contenido usando HTML5 semántico (<header>, <nav>, <main>, <section>, <footer>).

detalla el contenido de manera didactica y debe ser claro y estar bien organizado.

Módulo de Lógica (JavaScript Modular):

Toda la interactividad (ej. menús desplegables, modales, validaciones) debe estar en una sola etiqueta <script> justo antes de cerrar el </body>.

El código debe estar escrito en JavaScript moderno (ES6+) y ser modular (organizado en funciones claras, por ejemplo: initMobileMenu(), initEventListeners()).

Asegúrate de que los scripts se ejecuten después de que el DOM esté cargado (usando DOMContentLoaded).

Requerimiento Específico (Footer):

El <footer> de la página debe incluir el siguiente texto exacto: &copy; JMGV-PTEL-2025.Todos los derechos reservados.
